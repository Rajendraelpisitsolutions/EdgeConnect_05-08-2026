LicenseManager — Subsystem Architecture

The licensing core: loads a single RSA-PSS/SHA-256 signed license.json fully offline, verifies it against a public key embedded in the binary, freezes it into an immutable snapshot, and exposes lock-free checks. Three layers enforce it — and the data path is never blocked by licensing (locked decision #7).

Namespace ElpisEdgeConnect.Core.Licensing · Milestone B3 · verified against Sony_Development.

3Lifecycle state machine computed on every load and every Tick()

NotLoaded

no successful load yet

Only an empty config is allowed (first-boot). Any source/sink/route is rejected.

→ Valid / Grace / Expired on load

Valid

now ≤ expiresAt

All checks active. Warnings raised at 30 / 7 / 1 days before expiry.

→ InGracePeriod when now > expiresAt

InGracePeriod

expiresAt < now < +30d

Config changes still allowed with a warning attached. Data flow continues.

→ Expired at expiresAt + 30d

Expired

now ≥ expiresAt + 30d

Config changes blocked. Data flow still continues — never cut customer data to enforce licensing.

grace exhausted
Note: a signature/parse failure does not transition an already-loaded manager — LoadAsync throws and the prior snapshot is retained (the format spec's Invalid case manifests as an exception, not a status change).

4Three enforcement layers where the fast-path checks are consumed

① Packaging (build)

  • Per-edition installers decide which protocol assemblies ship at all
  • Starter / Professional / Enterprise

② Runtime activation

  • DI-registration — Add{Protocol}SourcesFromGatewayConfig calls IsModuleEnabled per source, skips cleanly when disabled (live today)
  • LicenseGate — config-apply walk: module enabled? instance caps? global limits? (Stage 3 of ConfigurationValidator)

③ UI / API

  • SourceProtocolPickerModel — RequiredLicenseModule → tile Available vs Requires-Premium
  • Probe / browse / test-connection API services gate on the module key
As-built nuance — the host builds ConfigurationManager with the default validator, so the config-apply gate is currently AllowAllLicenseGate. Live enforcement today = the DI-registration check (②) + UI picker (③). The full LicenseGate is implemented & unit-tested and drops straight in when config-time enforcement is switched on.
Two module-key spellings — DI + UI use hyphenated keys (source-melsec, from LicenseModuleKeys); LicenseGate builds dotted keys (source.melsec). Issue licenses with the hyphenated catalog keys today; reconcile before enabling the config-walk (ADR-worthy).
