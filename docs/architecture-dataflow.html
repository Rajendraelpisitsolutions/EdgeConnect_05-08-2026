Elpis EdgeConnect — Architecture & Data Flow

Protocol-agnostic industrial edge integration platform. Device data flows left→right: southbound adapters normalize to one CanonicalDataPoint, a deterministic transform pipeline shapes it, and the routing engine fans it out to many sinks over a mandatory per-route store-and-forward buffer. The data path is deterministic and never blocked by licensing.

Licensing (three-layer, offline)

  • LicenseManager — RSA-PSS/SHA-256 signed license.json, embedded public key
  • Runtime activation — IsModuleEnabled gates each adapter at DI time
  • LicenseGate — config-apply walk (modules · instance · global limits)
  • Expiry blocks config changes only — data keeps flowing

Diagnostics (three-way)

  • Source — adapter health, connection state, faults
  • Pipeline — transform metrics, drops, throughput
  • Sink — delivery, buffer depth, replay progress
  • Prometheus meters · diagnostic bundle (redacted)

Deterministic core, decision-support AI. The pipeline is replayable and testable end-to-end. AI agents live in the management layer, propose changes via structured tool calls, and every state change requires explicit human confirmation — they are never in the data path.
