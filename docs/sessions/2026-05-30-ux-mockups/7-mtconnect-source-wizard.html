Add MTConnect source

EdgeConnect maps an MTConnect agent to the same canonical CNC tags as every other machine protocol (status/run_state, spindle/speed, …). You don't pick individual dataItems — connect, and the wizard shows exactly which standard tags this agent can produce.
Mockup — MTConnect onboarding wizard (M.2b.4, sub-milestone M1 sign-off gate). FOCAS2-style semantic onboarding, not an OPC-UA-style dataItem picker. The wizard exposes the adapter's fixed semantic tag map, enriched by /probe only to make it accurate for the connected agent (real axis names, grey-out of tags this agent doesn't expose). Plan v2 is the source of truth. This page shows the happy path + every error/edge state for sign-off.

Agent unreachable

⛔ Couldn't reach the agent. Connection refused at mazak-vcn.shopfloor.local:5000. Check the URL, port, and that the MTConnect agent is running. (status: Unreachable)

Probe timed out

⏱️ No response within 10 s. The agent didn't return /probe in the probe budget. (status: Timeout)

Reachable, but nothing recognised

🟠 Agent reachable, but none of EdgeConnect's standard CNC tags are present. This agent's /probe exposes no Execution / Spindle / Position / … dataItems we map — the source would have 0 active tags. (status: ReachableNoRecognisedTags)
Save is blocked until you confirm an empty source is intended.
