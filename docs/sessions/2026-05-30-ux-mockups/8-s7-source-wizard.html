Accessibility (built in M3, in Razor)

  • Every field has a programmatic label (label for / aria-label).
  • Invalid rows set aria-invalid + aria-describedby pointing at the inline error.
  • Test connection / Test read results announce via role="status" + aria-live="polite".
  • Status column conveys ✓/⚠/✗ as text, not colour alone.
  • Planner-rejected datatype options are disabled (keyboard-skippable) with a reason in the option text.
  • Selected tag row exposes aria-selected; selection reachable by keyboard.
