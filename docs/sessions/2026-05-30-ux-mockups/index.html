  1. App-bar cosmetics (feedback #1) — header is now white with the purple "EC" mark as an accent, matching the rest of the Studio. Link colour aligned across all surfaces.
  2. Inspect entry flow + picker (feedback #2) — 3-tap-inspect.html now opens with the explanation "Inspect always focuses on one pair at a time" and adds a "Currently inspecting" picker showing the 20 most recently captured pairs so the operator can switch without going back to Compare.

  4. Capability Coverage rewritten for operators (feedback #4) — page renamed to Health checklist. The original runtime-consumer / enum-value / self-check-log table moves into a collapsible Advanced details (for support engineers) section.
  5. Source picker on detail pages (feedback #5) — 5-source-detail-metrics.html adds a "Looking at" combobox so the operator can switch sources without navigating back. The Live Tap pages already used this pattern via their Route picker — which is the same idea expressed for the route-centric views.

Cross-cutting design choices

  • Demand-driven by default. Every surface signals "Capturing" / "Comparing" / "live · updates every 5 s" so the operator knows the runtime is doing work because they're watching, and will stop 60 s after they leave.
  • Bounded buffers. Every list surface notes its capacity (1,000 pts/side for Stream; 30 s window for Compare). No unbounded queues; old data silently evicted.
  • Privacy at capture. Sensitive fields shown as *** with explanatory note. There is no "show real values" toggle anywhere by design (per ADR-0017).
  • Operator language, not engineer language. Where error codes appear they're paired with remediation hints. Capability Coverage explains what the matrix means; doesn't assume the operator has read ADR-0019.
  • Cross-launch between surfaces. SourceDetail has a "Open Live Data Tap for this source" button. Compare's transform-altered explanation links to the route pipeline. Inspect links to Source detail. The surfaces compose rather than islanding.
  • In-place pickers, not back-and-forth navigation. Each detail surface has a picker at the top — Route picker on Live Tap, "Currently inspecting" picker on Inspect, "Looking at" source picker on SourceDetail. The operator switches targets in place; they don't need to remember the route name and walk back through three pages.
Mockup limitations: static HTML — no SSE streams, no interactivity. Final Blazor implementations will animate the stream lists, update the verdict counts in real time, etc.
